Evaluation integrity and reproducibility

How to prepare an open release and how the HandWorldBench team verifies a leaderboard entry.

On this page Open releaseInputs and disclosures Official reproductionReporting scores

Open release

Each entry must identify a publicly accessible source repository and an open-source code license. Pin the commit or release and the checkpoint used for evaluation. Link the weights and their license so that the benchmark team and independent researchers can obtain and run the same model.

Include any inference adapters, preprocessing scripts, and configuration needed to generate the evaluated videos. Document the environment, hardware, commands, and seed settings. Identify any external models or dependencies and their versions.

Inputs and disclosures

Describe the inputs the generator receives for each of the three embodiments. Distinguish task text and the first RGB frame from hand controls, camera parameters, scene priors, and generated history.

For each derived input, explain how it was constructed and which frames it uses. In particular, disclose access to later reference frames, including indirect access through estimated depth, masks, or scene renderings. Identify any known overlap between model development data and benchmark evaluation cases.

Official reproduction

The HandWorldBench team will run the submitted release with the declared settings and score the resulting videos using the benchmark evaluation code. Provide settings that can be applied consistently across the evaluation set, including sampling, clip length, windowing, and any output selection.

If an artifact is missing or the instructions do not reproduce the run, the team will ask the named contact for clarification before listing a score. A change to weights, code, or settings should be identified by a new version so the team can reproduce the revised run.

Reporting scores

Official entries use the team’s reproduced results. Each submission runs on the full set of 500 cases. The leaderboard reports an overall score and a separate breakdown for each embodiment.

The summary displays HWBScore and six dimension scores on a 0–100 scale. Individual metrics use the paper’s 0–1 scale. A dash indicates structural inapplicability, such as hand morphology for real dexterous hands. These cells are excluded from the applicable metric average.
